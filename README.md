# Frontend Mentor – Gamer Sign-Up Form (NEONCORE)

Solución al reto [Gamer Sign-Up Form](https://www.frontendmentor.io/challenges/gamer-sign-up-form) de Frontend Mentor.

- **Sitio en vivo:** https://bernalbalderasivanyael-lab.github.io/gamer-sign-up-form/
- **Autor:** Ivan Yael Bernal Balderas – [@bernalbalderasivanyael-lab](https://www.frontendmentor.io/profile/bernalbalderasivanyael-lab)

## Funcionalidades

- Validación de gamertag, email, contraseña, confirmación y términos, con mensajes de error claros.
- Botones para mostrar/ocultar cada contraseña.
- Medidor de seguridad de contraseña que se actualiza mientras se escribe.
- Envío simulado con estado de carga y mensaje de éxito.
- Uso completo con teclado y soporte para lectores de pantalla (`aria-describedby`, `aria-invalid`, `aria-live`).
- Diseño responsivo (móvil, tablet y escritorio) con estados de hover y foco.

### Extras opcionales

- Operator ID que se actualiza en vivo con el gamertag.
- Animación de "shake" al enviar con errores (respeta `prefers-reduced-motion`).
- Ícono de éxito hexagonal que se dibuja solo.
- Aviso de Bloq Mayús activado.
- Estilos oscuros para autocompletado, selección de texto y scrollbar.

## Tecnologías

- HTML5 semántico
- CSS (custom properties, Grid, Flexbox, media queries)
- JavaScript (sin librerías)

## Cómo ejecutarlo

Descarga el repositorio y abre `index.html` en el navegador.
